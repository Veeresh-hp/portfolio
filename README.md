# Veeresh H P | Professional Portfolio

A modern, high-performance portfolio website built to showcase my projects, skills, and certifications. This project features a premium "Black Orange" aesthetic, fluid animations, and interactive AI-driven elements.

![Portfolio Preview](./frontend/public/hero-character.png)

## ✨ Key Features

- **🎨 Modern Aesthetics**: Dark-themed UI with glassmorphism, gradients, and a signature "Black Orange" color palette.
- **🖱️ Smooth Cursor**: Custom physics-based cursor implementation (inspired by Inspira UI) that reacts to movement and velocity.
- **🤖 AI-Powered Interactions**:
  - **Smart Contact Form**: "AI-Powered Draft" button simulates intelligent message generation for quick contact.
  - **Tools Hub**: Integrated CTA to my external AI Tools platform.
- **📱 Fully Responsive**: Optimized layout for all devices, including mobile-specific adjustments for navigation and visibility.
- **📄 Integrated Resume**: Direct access to view/download my resume from the Hero section.
- **🔧 Dynamic Content**: Data-driven architecture (`mock.js`) allows for easy updates to projects and skills.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Create React App](https://create-react-app.dev/)

## 🚀 Getting Started

Follow these steps to run the portfolio locally:

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Veeresh-hp/portfolio.git
   cd portfolio
   ```

2. **Navigate to the frontend directory**
   ```bash
   cd frontend
   ```

3. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```

   The application will open at `http://localhost:3000`.
